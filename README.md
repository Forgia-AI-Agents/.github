# Forgia-AI-Agents/.github

Portada de la organización en GitHub: [`profile/README.md`](profile/README.md).

Los SVG animados de `profile/assets/` se generan con `tools/build.py` (marca Forgia, fuentes Space Mono y
Plus Jakarta Sans incrustadas y recortadas, licencia OFL en `tools/fonts/`). Para regenerarlos:

```bash
pip install fonttools brotli
python tools/build.py
```

Las cifras de la portada son públicas y con fuente (las mismas de forgia.es). Nada de cómo funciona Forgia por dentro: esto es público.
